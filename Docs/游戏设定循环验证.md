# 游戏设定循环验证

> 2026-10-03；开发者：CCvTDD；Agent：Codex。由Codex记录。
> 目标：用可替换的测试占位，验证已经确定的玩法循环。未设计正式角色招式或定案平衡数值。

> 实跑复核未通过可玩性：默认AI下，两轮贴身操作约46秒生命100→34；此前复现的后退空砍与缺少战斗反馈已在下方更新中修正；血量收支问题仍需对比策略与调参。自动测试通过不能替代这些问题，详见[当前演示可玩性复核](当前演示可玩性复核.md)。

## 已连接的流程

普攻命中／击杀 → 正信心 → 冠冕 → 释放时归零。

附身敌人 → 普攻原角色 → 原角色受伤、负信心 → 到期返回 → 潮汐 → 释放时归零、授予冠冕吸血 → 再积累正信心 → 冠冕命中回血。

- 冠冕 ≥33、潮汐 ≤-33；达到 ±67 只获得对应强化资格，仍须按键释放。
- 没有装备、信心不足、冷却、动作进行中、死亡或控制门禁拒绝时不消费。已成功起手后被打断、空挥或目标离开不退款。
- 归零发生在释放成功瞬间；技能随后的命中仍走冠冕事件，因此命中后会有新的正信心。Debug 显示归零前信心和普通／强化快照。
- 信心留在身体上，附身不搬运信心／生命／阵营；返回原角色后使用原角色的负信心。
- AI 当前仅普攻，不自动消费冠冕／潮汐，避免出窍时消耗原角色已积累的资源。

## 操作

在 SampleScene 进入 Play，并点击 Game 画面获取键鼠焦点。

| 操作 | 键鼠 | 手柄 |
|---|---|---|
| 移动／普攻 | WASD／鼠标左键 | 左摇杆／X |
| 附身，约 10 秒自动返回 | V | LB |
| 冠冕／潮汐 | Q／E | RB／Y |
| Debug 状态面板 | F12 | View／Back |
| 重置本轮场景，包括死亡／附身中 | Backspace | Menu／Start |
| 暂停／恢复 Enemy 的 AI 普攻 | Debug 开启后 F8 | 暂无 |

技能与重置不要求开启 Debug。F8 仅隔离观察敌人普攻，不停止追击或修改伤害／信心规则；Enemy 被玩家附身时，玩家普攻不受此开关限制。重置后恢复保存的默认敌人攻击配置。

## 临时测试配置

两种技能复用现有近战攻击形状与出招节奏，通过数值验证强弱与强化；没有新增前方重击、范围爆发等角色招式。

按“需要贴脸和找角度”的试玩反馈，普攻及两个技能的普通／强化段统一使用前方水平扇形：半径2.5米、总角度140°（左右各70°），高度2米，中心为角色局部(0,1,0)。无需精确朝向目标，但背后或范围外不会命中；角度和距离按受击碰撞体最近点筛选。同段仍只结算一次，不增加锁敌、遮挡或扫掠。

| 参数 | 当前测试值 |
|---|---|
| 普攻伤害 | 3 |
| 冠冕普通／强化伤害 | 15／30 |
| 潮汐普通／强化伤害 | 30／60 |
| 两种技能冷却 | 各 1 秒 |
| Enemy AI 最小普攻起手间隔 | 1.5 秒（从两次请求之间计时） |
| 潮汐后冠冕吸血 | 20 秒、实际伤害的 100% |
| 命中／击杀收益 | +5／额外 +10 |
| 受击变化 | -5 |
| Player／Enemy 生命 | 100／200 |

有足够失血和目标剩余生命时，100% 吸血使普通／强化冠冕命中恢复 15／30 HP；生命不超过上限，击杀残血目标按实际扣血治疗。此前 3／6 的回血被受击掩盖，已按试玩反馈放大测试技能伤害，潮汐保持更高伤害。数值不代表正式设计。普通攻击和潮汐命中不吸血；重复潮汐刷新同一 Effect 的时长。

配置资产位于 `Assets/Scripts/Entity/Data/Skill/Demo/`：`Skill_TestCrown.asset`、`Skill_TestTide.asset` 与 `Effect_TestCrownLifeSteal.asset`。角色体质与事件量仍在 Character/Demo，普攻表仍在 Weapon/Demo。

菜单“Crown Tide → 配置 SampleScene 设定验证（测试占位）”通过 Editor API 装配并保存；保留已有测试技能调参，重新执行会设置双方技能引用及 Enemy 生命 200。正常 Play 不修改共享模板。

用户试玩发现潮汐后被 AI 连续受击抵消正信心，已为演示敌人配置最小起手间隔 1.5 秒。近距离等待时不继续顶着目标走；起手朝目标，本段动作期间保持方向。该值在 Enemy 的 AITreeInputSource／MeleeAttackInterval 调整，0 为旧的无额外限制行为；玩家附身后自己的攻击不受此 AI 间隔约束。重新执行演示配置菜单会将该值设回 1.5 秒。

## 建议试玩顺序

1. 先用常驻头顶资源面板观察正常AI对战中的信心积累、生命损失和跳字；需要详细状态时再开启F12。
2. 如需单独观察循环，按 F8 暂停敌人 AI 普攻。附身后朝向原角色攻击 7 次，原角色约损失 21 HP、信心达到 -35。
3. 等返回，靠近并朝向敌人按 E。释放瞬间归零，命中后产生新的 +5；面板显示吸血效果。
4. 继续普攻积累至 ≥33，按 Q，观察冠冕实际命中造成伤害并回血。普攻阶段应没有吸血。
5. 重置后观察满信心强化及正常敌人反击下的循环；判断付出的血量、操作时间和收益是否合理。

F8 隔离测试可以验证机制连接；默认 AI 对抗与人的选择、手感、风险收益仍需实际试玩。自动测试不构成可玩性定论。网络、救助、招架破防、障碍遮挡、动画与正式角色技能仍未实现。

## 实现与验证记录

技能 HasAttack 默认关闭；启用后以 ComboEntry 配置普通／强化段。Brain 校验后保存段数据、归零和冷却，再通过原 Action 状态执行。MeleeAttackHits 将技能种类传入 ResolveHit，伤害、信心与实际失血吸血走同一流程；普通攻击清除旧技能上下文。

重置只重载控制器所属场景：先结束双方附身并停用旧角色／相机，再装载新场景并卸载旧场景。没有原地清零模板或删除其他场景；临时效果、状态、信心、生命与冷却随新实例恢复。

最终验证结果与失败过程见 progress.md、findings.md；本地详细证据保存在忽略目录 `Logs/LoopValidation/`。

本轮最终编译 0 错误，EditMode 24/24、PlayMode 79/79 通过；其中 7 项技能攻击与 4 项保存场景循环／输入／重置测试。完整循环使用模拟键鼠与真实伤害／信心事件，独立强化用例直接设置边界值；没有物理手柄或人工手感验收。

## 2026-10-03｜攻击朝向与基础反馈更新

开发者：CCvTDD；Agent：Codex。由Codex记录。

- 玩家普攻／有攻击段的技能成功起手时朝自己的视角水平前方；后退、站定均可攻击画面前方。AI提交自己的目标方向，未引用全局相机。
- 前摇、命中和后摇期间保持本段起手方向，移动输入不再使扇形掉头；有效续段可重新选择方向。失败技能不转身、不消费。
- 首次接管载体时相机朝身体前方；返回使用过的身体保留此前视角。附身中卸载场景时不恢复已失效的InputUser配对。
- EntityCombatVisual常驻头顶生命／正负信心、技能资格／冷却、吸血和附身倒计时。F12切换详细Debug，避免两套面板叠放；玩家与非玩家用不同外观颜色区分。
- 地面线显示当前扇形方向／边界；起手变黄、命中阶段变亮、后摇变暗。敌人出招期间也显示范围。这是阶段提示，没有实现挥刀动画或额外攻击。
- 每次实际生命变更分别展示红色受击／绿色回血跳字并闪色；满血治疗不显示虚假恢复，同帧治疗与伤害不合成净值。资源仍只由原Logic／Data写入。
- 当前伤害、AI间隔、信心事件、阈值、技能归零与吸血机制保持原配置；操作改善不代表循环收支已平衡。
