## 已确认参数

| 项目 | 目标配置／行为 |
|---|---|
| 信心初始值 | 0 |
| 信心范围 | -67 至 +67 |
| 冠冕释放阈值 | 信心 ≥ +33 |
| 潮汐释放阈值 | 信心 ≤ -33 |
| 冠冕爆发条件 | 信心达到 +67 |
| 潮汐爆发条件 | 信心达到 -67 |
| 爆发释放方式 | 达到满值后按键释放强化版本，不自动释放（2026-10-03 确认） |
| 使用冠冕／潮汐 | 成功释放后信心归零 |
| 信心变化来源 | 冠冕事件增加，潮汐事件降低；技能释放不再推动信心 |
| 持续效果 | 使用统一 Effect 管理，模板与实体运行时实例分离 |

技能是否可释放还需通过统一能力门禁、已装备技能检查和现有冷却检查。最新文档没有取消冷却，不在本轮擅自移除。

## 当前资产与迁移范围

- `Assets/Scripts/Entity/Data/Character/Demo/Config_DemoPlayer.asset` 与 `Config_DemoEnemy.asset` 的 `FaithCapacity` 均为 67，已符合范围要求。
- 两份角色资产的 `FaithLossPerHit` 均为 5。这是当前演示配置，设计没有给出新变化量，保留原值；后续统一事件接入时再决定如何迁移。
- 用户已允许临时演示数值：双方命中敌怪 +5、击杀额外 +10，普通近战伤害 3；这些值已保存到演示资产，可调，不属于正式平衡定案。一般角色配置的新增收益字段默认仍为 0。
- 已新增 Skill/Demo 下的 Skill_TestCrown、Skill_TestTide 与冠冕吸血 Effect 测试占位资产，具体参数与试玩顺序见 [游戏设定循环验证](游戏设定循环验证.md)。没有正式角色技能资产或旧技能增量资产需要迁移。
- SkillSO 已移除旧 `Faith` 增量，改用 `FaithThreshold=33`；已有字段 `Effects`、`BurstEffects`、`AfterTideEffects`、`DispelOnCast`。当前没有旧技能资产需要迁移。
- ModifierEffect 已提供显式信心周期与冠冕吸血字段，默认关闭；通过 Unity 创建／配置资产，具体数值待确认。
- 测试技能配置 HasAttack／Attack／UseBurstAttack／BurstAttack，可复用同一近战出招段；测试吸血为 100%／20 秒、技能冷却各 1 秒。按 2026-10-03 回血不明显的试玩反馈，冠冕普通／强化伤害临时改为 15／30，潮汐为 30／60；有足够失血与目标生命时，冠冕分别回血 15／30。Enemy 最大生命为 200，均非正式平衡定案。
- 演示普攻和两个技能的普通／强化段均配置 `HitShape=Sector`、`HitRadius=2.5`、`HitAngle=140`、`HitHeight=2`、`HitOffset=(0,1,0)`。旧资产默认为 Sphere；扇形角度须在(0,360]、高度须为正，非有限参数与未知形状会被统一门禁拒绝。通过各段资产可单独调范围，不在 Logic 写死形状或演示数值。
- 现有附身效果与地板材质不属于本次迁移范围。附身仍使用目标限时载体和原角色永久标记。

## 待确认参数

- 满值爆发已确定为按键释放强化版本，普通／强化的具体效果仍待角色设计。
- 信心事件：命中、击杀、救助、受击、破防、友伤的变化量与重复结算规则。
- Buff／Debuff：触发时机、间隔、叠加结算，以及是否包括永久套装和附身纯标记。
- 潮汐后吸血：比例、持续时间／次数、是否覆盖普通攻击。
- 武器套装：指定套装的联动效果，以及武器是否计入护甲套装件数。

不得为以上未定正式参数自行补数值，也不得把旧问题清单中的建议当作定案；经用户许可的临时演示配置须明确标注。

## 后续验证要求

| 信心 | 信心门禁的预期结果（其他释放条件满足时） |
|---|---|
| -32、0、+32 | 两类技能均不可释放 |
| -33、-66 | 潮汐可释放，冠冕不可释放 |
| +33、+66 | 冠冕可释放，潮汐不可释放 |
| -67、+67 | 对应爆发条件成立，不再按旧规则锁住对应技能 |

测试已覆盖成功释放归零、失败不消费、归零前强化快照、满值不自动释放、钳制、冷却、控制门禁和同一信心事件实例去重。普通近战已覆盖同目标多碰撞体／多帧去重、连段重新结算、控制中断与低帧率窗口跨越；最新完整结果见 progress.md。

Debug 面板已去掉“钟摆”，显示当前信心、两类技能装备／可释放／强化状态及冷却；未装备时明确显示“未装备”。

此前 41/41 通过只证明旧阶段的附身、相机等用例通过，不能作为上述新规则的验收结果。
