| 决策 | 理由 |
|---|---|
| 两个 Effect 表达持续状态，Brain 保存每次双方关联 | 符合用户思路，同时准确归还控制权，不新增全局场景管理器。 |

| 剩余时长属于实例，初始计时类型在施加时确定 | 不运行时修改共享 SO，避免影响其他实体。 |
| 死亡返回视角不恢复操作 | 已死亡的原角色不能继续接收玩家动作。 |
| 保留目前普通驱散行为，但任一标记移除后收尾双方 | “附身不可普通驱散”仅是待确认建议，没有擅自定案。 |
| 不加入吸血或限制原角色 AI 选招 | 这些仍是待确认建议，不属于已授权的附身规则。 |
