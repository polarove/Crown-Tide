# 信心与技能代码实现

> **当前更新（2026-10-03）**：旧附身已取消。SkillSlot 新增 Weapon 第三槽与独立冷却，武器技能不要求／归零信心，成功释放起冷却、换武器保留；默认 V／LB 可改绑。空手配置在 CharacterSlotContainer.UnarmedWeaponSkill，武器配置在 WeaponSO.SpecialSkill；旧附身引用仅为历史记录。

> 2026-10-03；开发者：CCvTDD；Agent：Codex。范围：已确定规则的基础框架，不代表完整战斗或联机完成。

## 释放流程

输入／AI 请求 → `EntityCapabilities.CanCastSkill` → 装配、种类、冷却、控制与信心检查 → 保存强化快照 → 信心归零、启动冷却 → 驱散配置类别、施加统一 Effect。

- 冠冕默认 ≥33，潮汐默认 ≤-33；阈值幅度可在 SkillSO 配置。
- ±67 达到对应强化资格；用户已确认按键释放强化版本，不自动释放。
- `SkillCastResult` 保留归零前信心和强化结果；`LastSkillCast` 仅保存最后一次成功释放。
- `Effects` 为普通效果；强化时 `BurstEffects` 替代普通列表，空强化列表回退普通列表。`AfterTideEffects` 仅潮汐成功释放后额外施加。
- Effect 当前施加到释放者。范围伤害、目标选择、动画时序不是这些列表的隐含行为，需要后续执行模块。
- SkillSO 的 HasAttack 默认关闭；开启后以普通／强化 ComboEntry 复用 Action 出招状态、命中窗口与实体去重。释放时复制选中段，冠冕上下文随命中进入实际扣血吸血流程；普攻不会继承上一技能上下文。
- 无技能、错位种类、信心不足、冷却、死亡、控制、无效效果均拒绝消费。附身标记不能由普通技能单独施加。
- 解控技能须同时配置 `AllowWhileControlled` 与 `DispelOnCast`；控制状态仍由现有状态机更新。

## 事件与命中接缝

`ICrownEvent.Invoke()`／`ITideEvent.Invoke()` 通过 Logic 写入 SkillResource。`CrownEvent(entity, amount)` 增加，`TideEvent(entity, amount)` 降低；amount 必须非负。同一实例最多成功一次，没有全局静态总线。

- 现有 `TakeDamage` 受击入口接入潮汐事件，保留演示受击量 5；无效、零实际伤害不结算。
- 周期伤害明确 `countsAsHit:false`，不再被误当一次新受击。Debuff 的信心变化单独配置，避免双算。
- `ResolveHit(target, rawAmount, enemyHit, skillKind)` 提供伤害修正、敌怪命中／击杀信心事件、实际扣血吸血。敌我关系由调用方提供，不能用当前输入源推断阵营。
- `FaithGainPerEnemyHit`／`FaithGainPerEnemyKill` 默认 0，等待正式数值；救助、破防等未来机制可实现同一接口或创建事件。
- 信心事件按同一实例去重；普通近战另按攻击段／目标 Entity 去重，避免多碰撞体与重复帧反复结算。见 [近战命中与演示验证](近战命中与演示验证.md)。

## 持续效果与吸血

- `FaithDeltaPerTick` 正数走冠冕、负数走潮汐；`FaithTickInterval>0` 才启用。事件量按层数叠加，计时属于运行时实例；默认关闭。
- 不依据 Buff／Debuff 类别自动决定频率。永久套装和附身纯标记不会自行改变信心。
- `CrownLifeStealRatio` 默认 0；潮汐可通过 `AfterTideEffects` 授予带吸血的限时 Effect。实际冠冕命中按目标实际失血治疗，普通攻击暂不包含。
- 多个吸血效果按层数相加并限制到实际失血的 100%，这是当前框架的叠加方式，可后续调整；正式比例、时长与普通攻击范围尚未定案。测试样本不是正式平衡值。

## 装备与依赖

ModifierEffect、修饰枚举和统计枚举移到 Data，保留原 `.meta` GUID。装备数据不再持有或调用 ArmorSetBonusList；只发出 EquipmentChanged，Brain 订阅并同步套装。

WeaponSO 的 `Set` 与 `SetBonuses` 在指定护甲套装对应有效档位触发时联动。2／4 档同时满足时叠加；护甲与武器套装效果统一以永久实例施加，不修改模板；卸武器或破套会移除。武器是否计入件数尚未确定，当前保留原有护甲计数，不把武器纳入。

## 当前边界

普通近战命中、实体去重与 AI 近距离攻击已接入；SampleScene 使用经用户许可的临时数值，附身后可攻击原角色并降低其信心。阵营跟随身体配置，普通友伤不给攻击者冠冕收益。测试占位技能已接通阈值、按键强化、归零与吸血循环；尚无正式角色招式或平衡定案。多人权威、救助、招架破防尚未接入；传送门仅作设计例子。
