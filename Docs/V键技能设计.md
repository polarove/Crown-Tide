# 附身机制规范文档

---

## 一、术语与定义

### 1.1 信心值（Faith）
- 取值范围：`[-67, 67]` 的整数（正负区间）。
- `Faith == 0`：视为无信心资源，**无法使用 V 武器技能**。
- `Faith != 0`：可使用 V 武器技能。

### 1.2 死亡事实（IsDead）
- 判定条件：`红血 <= 0`。
- `IsDead` 为 **true** 时，红血始终为 0。

### 1.3 被附身状态（IsPossessed）
- 由状态机维护的独立状态：`"被附身"`。
- 与 `IsDead` **互不覆盖**，分别独立判断。

### 1.4 基础行动资格
- 可操作 = !IsDead || IsPossessed

### 1.5 系数（K）
- 统一配置常量，用于换算附身持续时间与绿血。

### 1.6 V 武器技能
- 技能标识：`V`。
- 资源消耗：**无**（技能本身不消耗资源）。
- 是武器所属类型的固定技能，不同武器只要武器类型一样，武器V技能的攻击动画就一样（定义说明，不要做动画）

---

## 二、死亡定义

- 判定条件：`红血 <= 0`。
- 红血归零后**保持死亡事实**，不恢复红血。
- `IsDead` 为 **true** 时，红血始终为 0。
- 死亡不清空 buff、debuff、faith 和其他任何状态，意味着附身后继承所有被附身目标的当前状态，不做任何修改。

---

## 三、附身开始时定义

### 3.1 触发条件

- 技能标识：`V`。
- 资源消耗：**无**。
- 触发前置：
  - `Faith != 0`（即 `|Faith| >= 1`）。
  - `Faith == 0` 时禁止使用。
- 触发结果：
  - 由**本次技能击杀**直接触发附身。
  - 不打断死亡动画播放（仅说明，理顺逻辑）。
  - 附身开始、结束**不消耗资源**。
  - 死亡动画播放中 → 被附身 → 顺滑过渡到正常操作的动画（仅说明，理顺逻辑）。
  - 玩家操作的Entity：PlayerInput -> AiTreeInput，也就是玩家角色会由自身AI接管进行行动
  - 被附身的Entity：AiTreeInput -> PlayerInput，也就是玩家能够操作

### 3.2 资源归属

- 附身期间使用技能，消耗的是**被附身的 Entity** 的：
  - 信心值
  - 技能冷却
  - 全部资源
- 即：操作主体切换为被附身 Entity 的资源池。

### 3.3 绿血显示

- 被附身时显示**隐藏的绿血**。
- 绿血计算公式：绿血 = Math.Abs(Faith) * 系数(K)
- 说明：
  - `Faith` 为施放 V 的 Entity 在释放时记录的信心值；计算绿血时取绝对值，正负信心均可附身。
  - `系数` 为统一配置常量（以 `K` 表示）。

### 3.4 附身持续时间

- 计算公式：附身持续时间(毫秒) = Math.Abs(Faith) * 系数(K)

- `Faith`：施放 V 的 Entity 在释放时记录的信心值。
- `K`：系数常量。

- 显示格式：
  - 以**秒**为单位显示，保留**一位小数**。
  - 示例：`3.2秒`。

---

## 四、附身时定义

### 4.1 行动资格

- 被附身时通过 `"被附身"` Buff 获得与存活角色一致的行动资格。
- 行动资格判定优先级：
  1. `!IsDead || IsPossessed`
  2. 眩晕检查
  3. 技能冷却检查
  4. 其他正常限制，就像玩家操作自己的角色一样
- 附身专属限制：**暂不添加**，后续再补充。
- 红血为 0 且正在被附身时，`IsDead` 仍为 `true`，但允许操作。

### 4.2 被命中与绿血消耗

- 被附身期间被命中：
  - 消耗**绿血**。
  - 按正常受伤流程处理。
  - 会受到 Debuff 影响。
- 绿血为被附身状态下的有效生命资源。


### 4.3 信心消耗
- 不变
- 消耗被附身的Entity的信心

---

## 五、附身退出时定义

### 5.1 退出条件

满足以下**任一**条件即退出附身：

1. **持续时间结束**
   - 达到 `Math.Abs(Faith) * K` 毫秒。
2. **绿血耗尽**
   - `绿血 <= 0`。

### 5.2 退出后处理

- 解除 `"被附身"` Buff。
- 解除玩家角色`"附身中"` Buff。
- 恢复原本的 `IsDead` 判定结果。
- 不消耗额外资源。
- 退出后若红血为 0，播放死亡动画（先别做动画相关，只是说明应该判定为死亡）。
- 玩家操作的Entity：AiTreeInput -> PlayerInput
- 被附身的Entity：PlayerInput -> AiTreeInput
