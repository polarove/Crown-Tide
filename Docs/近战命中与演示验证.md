## 数据与执行流程

输入／AI 请求 → Brain 能力门禁 → Attack 状态前摇 → 命中窗口形状检测 → 每目标去重 → ResolveHit → 实际伤害与信心事件 → 后摇／续段。

ComboEntry 提供 MeleeDamage、HitRadius、HitOffset、HitLayers 与 IncludeTriggers。默认伤害、半径或碰撞层为零时不启用检测；没有出招表的节奏兜底不会自动造成伤害。远程射击不因存在攻击段而自动变成近战。

现新增 HitShape：默认 Sphere 兼容旧资产；Sector 使用 HitRadius、HitAngle（总角度0～360°，须大于0）和 HitHeight（总高度，须大于0）。MeleeHitQuery 对扇形先查宽相盒，再按碰撞体最近点的水平距离与朝向夹角筛选，垂直范围由盒查询限制；这是碰撞体采样判定，不是任意复杂受击网格的精确扇形相交。未知形状、非有限值、非法角度或高度会拒绝命中；技能资格查询和实际释放共用配置校验。

- Physics 的 MeleeHitQuery 只查询碰撞体，缓冲可扩容。
- Logic 的 MeleeAttackHits 把子碰撞体归并为 Entity，排除自身、死亡与停用实体；同段每目标仅一次。
- 续段清空目标集合；起手复制连段数组，避免修改共享表时串段。
- 按前后累计时间区间与窗口相交判断采样，低帧率跨过整个窗口仍检测一次。没有加入历史位置插值或扫掠。
- 控制中断和输入源切换取消主动动作；中途取消后不继续结算查询里剩余目标。

## 阵营与 AI

CharacterConfigSO.FactionId 表示本体阵营；两个非零且不同的标识判为敌对。0 为未指定，不猜敌对。附身只更换输入源，阵营不变。

友伤可扣血并降低目标信心，不给攻击者命中敌怪的冠冕收益。所有命中走既有 ResolveHit／TakeDamage 与事件接口；没有静态命中总线。

AI 的 EnableMeleeAttack 默认关闭。显式启用后进入 MeleeAttackRange 会提交普通攻击请求，仍由 Brain 仲裁；这里没有直接扣血或绕开状态机。当前场景原角色保留原有追击目标，其近战开关关闭，不自动补反击策略。

## 2026-10-03｜攻击朝向与基础反馈更新

开发者：CCvTDD；Agent：Codex。由Codex记录。

- 玩家普攻／有攻击段的技能成功起手时朝自己的视角水平前方；后退、站定均可攻击画面前方。AI提交自己的目标方向，未引用全局相机。
- 前摇、命中和后摇期间保持本段起手方向，移动输入不再使扇形掉头；有效续段可重新选择方向。失败技能不转身、不消费。
- 首次接管载体时相机朝身体前方；返回使用过的身体保留此前视角。附身中卸载场景时不恢复已失效的InputUser配对。
- EntityCombatVisual常驻头顶生命／正负信心、技能资格／冷却、吸血和附身倒计时。F12切换详细Debug，避免两套面板叠放；玩家与非玩家用不同外观颜色区分。
- 地面线显示当前扇形方向／边界；起手变黄、命中阶段变亮、后摇变暗。敌人出招期间也显示范围。这是阶段提示，没有实现挥刀动画或额外攻击。
- 每次实际生命变更分别展示红色受击／绿色回血跳字并闪色；满血治疗不显示虚假恢复，同帧治疗与伤害不合成净值。资源仍只由原Logic／Data写入。
- 当前伤害、AI间隔、信心事件、阈值、技能归零与吸血机制保持原配置；操作改善不代表循环收支已平衡。
